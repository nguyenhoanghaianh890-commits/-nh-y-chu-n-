Cài đặt iOS

1
Cấu hình DPI (Mobileconfig)Tải file cấu hình DPI Luxury
⬇ Tải File Cấu Hình DPI
2
Dấu câu (Kéo tâm)Bấm tải file bên dưới
⬇ Tải File Dấu Câu
3
Cách cài đặtVào Cài đặt > Cài đặt chung > Quản lý thiết bị. Bấm vào cấu hình và chọn Cài đặt (Install).
